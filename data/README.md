# Data layout (not committed)

```
data/raw/train/<trip_id>/<trip_id>.{track,nodes,arcs,route}         80 training trips
data/raw/student_test/<trip_id>/<trip_id>.{track,nodes,arcs,route}  10 student-test trips
data/eval/<trip_id>/<trip_id>.{track,nodes,arcs,route}              10 evaluator trips (demo day only)
data/processed/                                                      generated by scripts/build_dataset.py
```

Copy the provided `Student folder/train` and `Student folder/student_test` into `data/raw/`.
The evaluator trips go into `data/eval/` on Laptop 1 only (or point `PATHSNAP_EVAL_DIR` at them).
They are never used for training, feature selection, or tuning.
